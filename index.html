About

Over about 6 years, I've grown from junior UI designer to design system manager. I built v1, our component library, with 45 components across React, Vue and Angular, and delivered it in four stages against a roadmap I presented at CTO level.

When the evidence said a library couldn't keep up, I retired my own work and replaced it with a specification that AI coding agents build from. I run that spec as a product. Strategy, roadmap, releases and adoption are mine, and the Head of UX co-sponsors it.

Earlier operational changes I led saved £94k a year, mostly by merging a separate component build function into one design operations role.
