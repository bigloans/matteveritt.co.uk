Running a design system with 15 agents

I run the design system as a team of one, with a harness of 15 specialist agents and 7 contributing designers. Agents do measurable work, but spec and release decisions stay with me.

A team of one

Each agent in the harness has one job and a written standard. Any edit that moves a brand value stops until it is explained, and no bug is fixed until one agent reproduces it and another checks the fix.

Where designers work now

Without Figma handoff, designers build in the same session as an AI agent, against the pinned spec, so nobody has to memorise a rulebook. So far, 7 designers have contributed 47 catalogue entries.

  1. Designer

    Builds a screen

    The agent generates it from the designer's description.

  2. Agent

    Spots a missing asset

    No pictogram fits, so the agent offers to draft one in the session.

  3. Agent

    Applies the rules

    It checks for duplicates, follows the style guide and opens a review.

  4. Gate

    Flags the draft

    It lists the draft without failing the build, so nothing ships unseen.
