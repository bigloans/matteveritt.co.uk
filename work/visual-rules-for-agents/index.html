Visual rules an AI agent can follow

An agent can't interpret “make it feel premium”, so each aesthetic decision in the spec is a named rule with a token behind it. These are three of them.

Short read, 1 minute

Role
Product owner, designer and front-end lead
Scope
The visual language of a spec for 60+ products
Timeline
Spec work from Jul 2026

Two themes from one set of tokens

Dark is the signature theme. Light is the working surface. The same tokens drive both, so an agent never picks colours for a theme. It picks a role, and the theme supplies the value.

Radius by role

Components reference a role, never a raw value, so one edit changes every card's corner. A modal, a surface, a control and a pill each get their own radius, so hierarchy shows in the corners.

AI disclosure, designed for regulation

The AI disclosure component marks AI-produced content and supports disclosure under Article 50 of the EU AI Act, applicable since 2 August 2026. It doesn't cover machine-readable marking.

  • Always visible, never dismissible
  • Always labelled in text, never colour alone
