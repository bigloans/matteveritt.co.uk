This site's spec

Every value on this site comes from one token file. The same file draws the "Show the spec" annotations and this page, so the three can't drift apart.

Spacing

Every margin, padding and gap uses one of these steps. Below 900px, the gap between sections steps down from 96 to 64 and the gap between blocks from 48 to 32.

Radius

Radius follows the role an element plays, so hierarchy shows in its corners.

  • --radius-control: 10pxButtons, inputs, contents button
  • --radius-surface: 16pxGate output, recreation frames, tables
  • --radius-modal: 20pxContents sheet, recreated modal
  • --radius-pill: 999pxStatus and disclosure labels
  • --radius-circle: 50%Theme toggle

Elevation and borders

One shadow, --shadow-overlay, lifts the contents sheet above the page. Content surfaces get none. A 1px --color-hairline border separates the header, the footer and the two kinds of work on the landing page.

--shadow-overlay

Motion

Motion only follows something you do. "Show the spec" fades its annotations in over --motion-fast, 200ms, and the contents sheet opens at the same speed. Nothing animates on scroll or on hover. With reduced motion set, --motion-fast becomes 0ms.
