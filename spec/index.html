Every value on this site comes from one token file. The same file draws the "Show the spec" annotations and this page, so the three can't drift apart.

Gradient and pattern

The brand sweeps from teal through blue to pink. It runs along the top of the header, borders the chosen cards and colours one phrase per headline. Every stop clears 3:1 against navy, so gradient type stays readable as large text. Soft aurora glows sit behind the navy bands and run the length of each page.

  • --gradient-brandBrand sweep: teal, blue, pink. Used where the brand is the subject, and as the header rule
  • --gradient-textGradient type. Every stop clears 3:1 for large text on navy
  • --gradient-auroraDrifting glow behind navy bands
  • --gradient-surface-glowFaint glow on page-surface panels
  • --gradient-page-glowFaint glows spread down the whole page, so sections flow into each other
  • --pattern-spec-gridThe grid behind "Show the spec": an 8px baseline and 48px columns

Elevation and borders

Three shadows do three jobs. --shadow-overlay lifts the menu and contents sheets, --shadow-card lifts a card you point at, and --shadow-glow marks the one action or piece of work that matters most. A 1px --color-hairline border separates kinds of content.

Motion

Motion adds a little joy without getting in the way of reading. Aurora glows drift slowly, headlines sharpen into focus, sections ease in as they arrive and figures count up once. "Show the spec" fades in a grid, then draws each measurement top to bottom. With reduced motion set, every duration becomes 0ms and nothing moves.
